Install on Fire TV / Android TV (using Downloader)

  1. Turn on installs from unknown sources: Settings → My Fire TV → Developer Options → Apps from Unknown Sources → ON. If Developer Options is hidden, go to Settings → My Fire TV → About and click "Fire TV Stick" 7 times.
  2. Install the Downloader app from your TV's app store.
  3. Open Downloader and type this URL:
    github.com/YamanAddas/yancotv-releases/releases/latest/download/yancotv.apk
    Long, but it skips the landing page entirely and grabs the APK in one shot — saves you a remote click.
  4. The APK downloads directly. Click Install when it finishes.

Install on Android phone or tablet

  1. Allow installs from unknown sources for your browser.
  2. Tap Download Latest APK above, then open the downloaded file.
Only install YancoTV from this page or from our GitHub releases.

If you find YancoTV on a third-party APK site, it did not come from us — don't install it. Every legit build is signed with the same key and listed here first.

You provide the content

YancoTV is a player — it doesn't include playlists, channels, or accounts. After installing, open Settings → Sources and add yours: M3U URL, Xtream Codes (host + username + password), Stalker portal (URL + MAC), or XMLTV EPG. Use only with content you have rights to access.
